# First PR Practice

A tiny sandbox repo for practicing the GitHub pull request workflow: clone, branch, commit, push, open a PR, merge.

## Git Command Cheatsheet

| Command | What it does |
| --- | --- |
| `git status` | Shows the state of the working directory and staging area |
| `git add <file>` | Stages changes for the next commit |
| `git commit -m "msg"` | Recods a snapshot of staged changes |
| `git push` | Uploads local commits to the remote repository |
| `git pull` | Fetches and merges changes from the remote repository |
| `git branch <name>` | |
| `git checkout -b <name>` | Creates and switches to a new branch |

## Workflow

1. Create a branch off `main` for your change.
2. Make a small, focused edit.
3. Commit with a clear message.
4. Push the branch and open a pull request.
5. Review, then merge.
